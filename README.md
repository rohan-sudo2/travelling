# 🌍 Wanderlust - Travel Website

A modern and responsive travel website built using **HTML, CSS
(Tailwind), and JavaScript**.\
Wanderlust allows users to explore destinations, view travel packages,
and contact travel experts for bookings.

------------------------------------------------------------------------

## ✨ Features

-   🌐 Responsive design (mobile + desktop)
-   🗺️ Beautiful destinations showcase
-   📦 Travel packages section
-   📞 Contact form with validation
-   📱 Mobile-friendly navigation menu
-   🎨 Modern UI with Tailwind CSS
-   ⚡ Smooth hover effects and animations

------------------------------------------------------------------------

## 🛠️ Tech Stack

-   **HTML5**
-   **Tailwind CSS**
-   **JavaScript (Vanilla)**
-   **Font Awesome Icons**
